# Toolbox

A small collection of developer utilities I use for local projects and experiments.

- `read.py` exports a folder tree, file inventory, and text-file contents to a single snapshot. Set its input and output paths before running it.
- `env/` contains a Windows development-environment audit script and its own README.
- `ops-toolbox/terraform-deps-clean/` contains a Terraform local-artifact cleanup script. Its README describes the dry-run and apply modes.

These tools are independent; see the README or source in each folder for usage details.
